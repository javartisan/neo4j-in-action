# 知识图谱 KG

> 来源：知识图谱技术体系思维导图整理

```
                        ┌──────────────┐
                        │ 知识图谱 KG  │
                        └──────┬───────┘
           ┌───────────┬───────┼───────┬───────────┐
           ▼           ▼       ▼       ▼           ▼
       知识表示     知识获取   知识存储  知识推理    知识融合
```

---

## 1. 知识表示

定义概念、关系及其形式化表达方式。

| 要点 | 说明 |
|------|------|
| **Ontology** | 本体：约定领域内的概念、属性与关系体系 |
| **RDF/OWL** | 语义网标准：用三元组与本体语言描述知识 |
| **Embedding** | 嵌入表示：将实体与关系映射到连续向量空间 |

精炼笔记 → [`1、知识表示-精炼学习笔记.md`](./1、知识表示-精炼学习笔记.md)

---

## 2. 知识获取

从非结构化/半结构化数据中抽取知识。

| 要点 | 说明 |
|------|------|
| **NLP 抽取** | 基于自然语言处理的知识抽取流水线 |
| **NER** | Named Entity Recognition，命名实体识别 |
| **RE** | Relation Extraction，关系抽取 |
| **EE** | Event Extraction，事件抽取 |

精炼笔记 → [`2、知识获取-精炼学习笔记.md`](./2、知识获取-精炼学习笔记.md)

---

## 3. 知识存储

持久化与查询知识图谱。

| 要点 | 说明 |
|------|------|
| **图数据库** | 以图模型存储节点与边，适合关联查询 |
| **Neo4j** | 主流属性图数据库（Bolt / Cypher） |
| **RDF** | 以 RDF 三元组库形式存储语义数据 |

---

## 4. 知识推理

由已有知识推导隐含事实。

| 要点 | 说明 |
|------|------|
| **规则推理** | 基于逻辑规则、产生式规则推导新知识 |
| **本体推理** | 基于本体公理（传递、包含、互斥等）推理 |
| **Embedding** | 基于向量表示做链接预测、补全与推理 |

---

## 5. 知识融合

整合多源知识，消除冗余与冲突。

| 要点 | 说明 |
|------|------|
| **实体对齐** | 识别并合并指向同一现实对象的不同实体 |
| **本体匹配** | 在不同本体/模式之间建立概念对应关系 |
| **冲突消解** | 对矛盾信息做取舍、置信度加权或人工裁决 |

---
